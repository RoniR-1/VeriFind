# VeriFind (1st Place - The Hague Policy Hackathon 2026)

**Policy Brief:** [📄 Read the Full Document Here](./Media/PolicyBriefVeriFind.pdf)

### The Challenge
AI-accelerated disinformation campaigns are scaling faster than reactive fact-checking can handle which is limited by Technology and Ethicss, posing a critical threat to civic infrastructure and democratic discourse. 

### The Solution
VeriFind is an interactive, web-based serious game built in 48 hours to proactively inoculate citizens against disinformation. It gamifies the SIFT framework (Stop, Investigate, Find better coverage, Trace claims) and lateral reading, teaching users how to verify sources rather than relying on automated censorship.
